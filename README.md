# مأموریت‌نگار ۲۰۲۷ (MissionLog 2027)

اپلیکیشن وب ثبت مأموریت‌های روزانه کاری با **تقویم شمسی (جلالی)**، داشبورد آماری، تاریخچه قابل فیلتر و **گزارش رسمی PDF** — کاملاً فارسی، راست‌به‌چپ و موبایل‌محور.

---

## ۱) اجرای محلی

هیچ نصب و Build لازم نیست — فقط HTML5 خالص:

**روش ساده:** فایل `index.html` را در مرورگر باز کنید (دابل‌کلیک).

**روش پیشنهادی (سرور محلی):**

```bash
# هر کدام که راحت‌ترید:
npx serve .
python -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.

> نیازمندی اینترنت: فونت وزیرمتن (Google Fonts) و دو کتابخانه PDF (html2canvas + jsPDF از CDN) هنگام ساخت اولین PDF از اینترنت بارگذاری می‌شوند. بقیهٔ برنامه کاملاً آفلاین کار می‌کند.

## ۲) استقرار آنلاین

برنامه کاملاً استاتیک است؛ روی هر هاست استاتیکی قرار دهید:

- **Netlify:** پوشه را در app.netlify.com/drop بکشید و رها کنید.
- **GitHub Pages:** ریپو بسازید، فایل‌ها را push کنید، در Settings → Pages شاخه `main` را انتخاب کنید.
- **Vercel:** `vercel deploy` در پوشهٔ پروژه.

## ۳) ذخیره‌سازی داده‌ها

### حالت پیش‌فرض: محلی (localStorage)
تمام رکوردها در حافظهٔ مرورگر ذخیره می‌شوند و با بستن مرورگر یا ری‌استارت دستگاه از بین نمی‌روند. **محدودیت:** داده‌ها بین دستگاه‌ها یا مرورگرهای مختلف منتقل نمی‌شوند؛ برنامه هرگز این محدودیت را پنهان نمی‌کند (در تنظیمات، وضعیت ذخیره‌سازی «محلی» نمایش داده می‌شود).

### حالت اختیاری: همگام‌سازی ابری با Supabase
1. در [supabase.com](https://supabase.com) یک پروژه بسازید.
2. در SQL Editor محتوای فایل `supabase-schema.sql` را اجرا کنید (جدول `missions` + سیاست‌های RLS — هر کاربر فقط به دادهٔ خودش دسترسی دارد).
3. از Project Settings → API مقدار **Project URL** و **anon public key** را بردارید.
4. در برنامه: تنظیمات → اتصال ابری → آدرس و کلید را وارد کنید → «اتصال» → ثبت‌نام/ورود → «همگام‌سازی».

> کلید anon عمومی است (نه secret) و در کد فرانت‌اند قرار دادنش خطر امنیتی ندارد؛ امنیت واقعی با Row Level Security تضمین شده است. کلید `service_role` را هرگز در فرانت‌اند قرار ندهید.

## ۴) پشتیبان‌گیری

تنظیمات → «دریافت فایل پشتیبان» (فایل JSON) و «بازیابی پشتیبان» (ادغام هوشمند بر اساس شناسه و تاریخ آخرین تغییر).

## ۶) قابلیت‌های پیاده‌سازی‌شده

- ثبت مأموریت با تاریخ پیش‌فرض «امروز» + امکان انتخاب تاریخ گذشته
- محاسبهٔ خودکار روز هفته از تاریخ انتخابی
- ۵ مقصد ثابت: گمرک گرمسار، گمرک سمنان، گرمسار، ایوانکی، سمنان
- چند مأموریت در یک روز، ویرایش و حذف با تأیید
- هفتهٔ کاری شنبه تا چهارشنبه در آمار هفتگی و گزارش هفتگی
- داشبورد: تاریخ امروز (جلالی)، آمار امروز/هفته/ماه، خلاصه بر اساس مقصد، آخرین رکوردها — همه از دادهٔ واقعی
- تاریخچه با گروه‌بندی روزانه، هایلایت امروز، جستجو و فیلتر (بازهٔ تاریخ، مقصد، روز هفته، ماه جلالی)
- گزارش PDF: روزانه، هفتگی، ماهانه، بازهٔ دلخواه + پیش‌نمایش قبل از خروجی
- PDF چندصفحه‌ای با صفحه‌بندی خودکار جدول، شماره صفحه فارسی، سربرگ/پاورقی، فونت وزیرمتن، شکل‌دهی صحیح حروف فارسی
- پوسته روشن/تاریک، طراحی موبایل‌محور، حالت‌های خالی و پیام‌های موفقیت/خطا
- جلوگیری از ثبت تکراری (قفل دکمه + هشدار رکورد مشابه)، تأیید قبل از حذف، پشتیبان‌گیری/بازیابی

## ۷) چک‌لیست تست دستی (قبل از استفادهٔ رسمی اجرا کنید)

> شفاف‌سازی: این کد در محیط اجرایی این پیام **اجرا نشده است**؛ منطق تقویم دقیقاً بر اساس الگوریتم استاندارد و تست‌شدهٔ `jalaali-js` پیاده‌سازی شده، اما لطفاً این چک‌لیست چنددقیقه‌ای را طی کنید:

1. ثبت مأموریت با تاریخ امروز → روز هفته باید درست باشد.
2. انتخاب تاریخ گذشته از تقویم‌گر → روز هفته به‌روز شود.
3. ثبت دو مأموریت در یک روز → هر دو در گروه همان روز نمایش داده شوند.
4. ثبت هر ۵ مقصد و ویرایش/حذف هرکدام.
5. جستجو و فیلتر (بازه، مقصد، روز، ماه) → شمارنده و خالی‌بودن حالت بدون نتیجه.
6. آمار امروز/هفته/ماه با دست‌شماری مقایسه شود.
7. مرز ماه جلالی: گزارش ماهانهٔ ماه قبل و سال قبل را بسازید (مثلاً اسفند سال کبیسه).
8. گزارش هفتگی: بازه باید شنبه تا چهارشنبه باشد.
9. ساخت PDF با بیش از ۳۰ رکورد → ادامهٔ جدول در صفحات بعد + شماره صفحات.
10. رفرش صفحه و بستن مرورگر → داده‌ها باقی بمانند.
11. تست موبایل (کروم DevTools) و دسکتاپ.
12. در تنظیمات: پشتیبان‌گیری، بازیابی، حذف همهٔ داده‌ها.

## ۸) محدودیت‌های شناخته‌شده

- خروجی PDF به‌صورت رندر تصویری از صفحات A4 است (برای تضمین صحت کامل حروف فارسی). متن داخل PDF قابل انتخاب/جستجو نیست؛ برای نسخهٔ برداری از دکمهٔ «چاپ گزارش» و Save as PDF مرورگر استفاده کنید.
- کتابخانه‌های PDF و فونت از CDN بارگذاری می‌شوند؛ برای محیط کاملاً آفلاین می‌توانید آن‌ها را دانلود و به‌صورت لوکال در `index.html` معرفی کنید.
- سینک ابری فقط در صورت پیکربندی Supabase فعال است؛ در غیر این صورت برنامه صادقانه «ذخیره‌سازی محلی» را نشان می‌دهد.
